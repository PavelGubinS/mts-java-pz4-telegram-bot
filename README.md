# Telegram-бот для поиска книг и IT-проектов

Практическое задание №4 по дисциплине «Объектно-ориентированное программирование на Java».

## Описание проекта
Telegram-бот реализован на языке **Java** с использованием фреймворка **Spring Boot** и библиотеки **TelegramBots** (режим Long Polling). Бот предназначен для поиска технической литературы по названию или автору, а также популярных IT-репозиториев по ключевым словам через REST API в формате JSON.

## Архитектура и принципы ООП
Приложение построено с соблюдением принципов ООП и четким разделением ответственности между слоями:
- `ru.urfu.bot` — точка входа (`TelegramBotApplication`), конфигурация бинов (`BotConfig`) и основной обработчик входящих обновлений (`HelperTelegramBot`).
- `ru.urfu.bot.command` — реализация поведенческого паттерна **«Команда» (Command)**: базовый интерфейс `BotCommand` и изолированные классы-обработчики (`StartCommand`, `HelpCommand`, `BookCommand`, `RepoCommand`).
- `ru.urfu.bot.service` — сервисный слой (`BookService`, `GitHubService`), выполняющий HTTP-запросы через `java.net.http.HttpClient` и разбор JSON-ответов с помощью Jackson `ObjectMapper`.
- `ru.urfu.bot.controller` — REST-контроллер (`LocalCatalogController`), предоставляющий JSON-эндпоинты `/api/books` и `/api/repos`.

## Команды и пользовательский интерфейс
Бот оснащен клавиатурой быстрого доступа (`ReplyKeyboardMarkup`) из 4 кнопок и поддерживает следующие команды:
- `/start` — приветственное сообщение и отображение клавиатуры меню.
- `/help` (или кнопка **«Справка»**) — вывод списка всех доступных команд с примерами использования.
- `/book <запрос>` (или кнопки **«Книги по Java»**, **«Книги Clean Code»**) — поиск книг по названию или автору (например: `/book Effective Java`).
- `/repo <запрос>` (или кнопка **«Топ проектов GitHub»**) — поиск IT-проектов по ключевому слову (например: `/repo spring`).

Также реализована защита от некорректного ввода: бот корректно обрабатывает пустые аргументы команд, неизвестные запросы, нетекстовые сообщения (стикеры, медиафайлы) и сетевые ошибки при обращении к API.

## Настройка и запуск

### 1. Требования
- **JDK 17** или выше
- **Gradle** (в проект включен Gradle Wrapper)
- Зарегистрированный бот в Telegram через `@BotFather`

### 2. Конфигурация
Секретный токен бота не хранится в исходном коде и передается через переменную окружения:
- `TELEGRAM_BOT_TOKEN` — токен авторизации, полученный от `@BotFather`.

### 3. Сборка и запуск
```bash
git clone https://github.com
cd mts-java-pz4-telegram-bot
export TELEGRAM_BOT_TOKEN="ваш_токен"
./gradlew bootRun
```
